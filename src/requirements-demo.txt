# VeriTrack laptop demo — live webcam ANPR, CPU-only (no GPU required)
#
# Target: Intel i5 13th-gen, Windows 11 native Python (recommended) or WSL2
# Ubuntu with a USB camera attached via usbipd-win. See README.md
# ("Stage 1 laptop demo") for the Windows/WSL2/Docker decision and why the
# camera capture step specifically should run natively on Windows.
#
# Install with the SAME Python environment you will run the demo from:
#   python -m venv .venv
#   .venv\Scripts\activate            (Windows)  or  source .venv/bin/activate (WSL2)
#   pip install -r requirements-demo.txt

# ---------------------------------------------------------------------------
# PyTorch — CPU build. The default PyPI index resolves a much larger CUDA
# build even on a machine with no GPU; the dedicated CPU index avoids that
# multi-GB download entirely. If this index is unreachable from your network,
# omit --extra-index-url and let pip's default CPU fallback resolve instead.
# ---------------------------------------------------------------------------
--extra-index-url https://download.pytorch.org/whl/cpu
torch>=2.2,<3.0

# ---------------------------------------------------------------------------
